# Series01-python: ECG signal analysis using Python

Loading, rescaling and plotting a 3-lead ECG signal (leads I, II, III) recorded at 1000 Hz. Part of Series01 of the Python-R-Git course,
Master IEAP, University of Montpellier.

## Data

`data/ECGu.txt` - 6500 samples x 3 leads, raw A/D units (gain 1024 µV/unit).
